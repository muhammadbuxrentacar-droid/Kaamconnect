KAAMCONNECT PREMIUM NO-OTP DEMO

This is a mobile-friendly PWA/browser prototype package, NOT a compiled Android APK.

CHANGES IN THIS VERSION
- Removed OTP screen and demo OTP code. Continue directly into selected demo role.
- Premium dark navy + champagne-gold styling, refined cards and spacing.
- No demo/sample technicians are preloaded; worker directory starts empty.
- Added a worker management form so you can enter your own workers.
- Retains booking requests, estimate approval, statuses, Repair Passport, reviews and admin view.
- English + Urdu labels remain on key customer screens.

TRY IT
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Enter any phone label (or leave blank for Guest), choose Customer or Admin and tap Continue.
4. As Admin, open Workers and add your own workers.
5. Create bookings as Customer; review/assign estimates as Admin.

IMPORTANT LIMITATIONS
- This is still a browser prototype, not an APK.
- OTP was removed for demo convenience; there is no real login/security.
- Data is stored in localStorage on this browser/device only; it will not sync between phones/users.
- Worker details are whatever you enter; the app does not verify identities or skills.
- No live payments, SMS, GPS or push notifications.
- HTTPS hosting is needed for PWA installation; a genuine APK needs Android packaging/building and testing.
